# Music loops

These are recordings of the game's own code-made songs (the sequencer in the sound script at the end of build/template.html),
saved as seamless loops so music plays smoothly on slower devices. If a file can't load, the game makes the song live in code instead.
Nothing here is AI-generated audio. Each file is one loop with 0.3 s of overlap on each side; the game loops from 0.3 s for exactly one loop length.
